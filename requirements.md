# Movie Theater Ticket Kiosk Requirements

| ID | Requirement |
|----|-------------|
| R1 | A customer can view available movies and showtimes. |
| R2 | A customer can choose an available seat. |
| R3 | A customer can purchase a ticket. |
| R4 | The system provides a confirmation after purchase. |
| R5 | The system must prevent the same seat from being sold twice. |
